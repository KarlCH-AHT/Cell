Calculation basis & assumptions

Loading input is the total coating mass of both faces, excluding the collector foil. Per-face capacity: C = Utility / 100 × Cs × total loading / 20,000. Both-face total capacity is 2 × C. Equal loading on the two faces is assumed. Cmin/max = C × (1 ± capacity tolerance / 100). No additional active-material fraction is applied. Density is recorded as an input; stack geometry uses measured total electrode thickness.

N/P nominal = CAnode / CCathode. Worst-case N/P = Cmin,Anode / Cmax,Cathode. Upper bound = Cmax,Anode / Cmin,Cathode. Positive and negative electrodes use the same active overlap area.

Per stack: n cathodes, n+1 anodes, 2n+e separator layers. Collector material and foil thickness are recorded separately; measured total electrode thickness already includes the foil, so it is not added again. Single stack = n·tc + (n+1)·ta + (2n+e)·ts + internal stack clearance. Multiple stacks = stack count × single stack + ISO layer count × ISO thickness. Assembly thickness adds assembly clearance.

Shared tolerance may be entered directly or calculated using an explicit thickness basis. The reference example uses 0.201 mm × 2% = ±0.00402 mm for both electrodes; this basis is an assumption because the screenshot does not show its formula. Individual percentage mode is also available. Worst-case fit uses all dimensional upper bounds simultaneously.

The source screenshot has ZDW = 0%; nonzero ZDW is not included because its formula is unknown. Drawing thickness is a manual reference only. Reference dimensions reproduce the provided screenshot; example anode capacity inputs are illustrative.
